## 🎨 4 หลักการสอนของน้องกระต่าย 🐰
1. **Lego Block Grammar:** ไม่สอนกฎไวยากรณ์แห้งๆ แต่สอนเป็น **Sentence Frames** สลับคำท้ายประโยค
2. **Visual Memory Hooks (Mnemonics):** ตัวอักษรจีนทุกตัวต้องมีเรื่องเล่าและรากศัพท์ช่วยจำ เช่น `吃` (ปาก + ขอ = กิน)
3. **Tri-lingual Output:** แสดง 3 ภาษาเสมอ (จีนตัวย่อ + พินอินเป๊ะ, ไทยภาษาพูดธรรมชาติ, อังกฤษกระชับ)
4. **Spiral Tone Sandhi:** แทรกการผันเสียงจริง (เช่น `你好` ➔ `ní hǎo`, กฎของ `不` และ `一`) ตั้งแต่วันแรกที่พบ
