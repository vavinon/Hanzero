# 📱 02 - Hanzero Feature Specifications (ฉบับปรับทัพ: เรียบง่าย ตรงจุด ใช้งานได้จริง)

เอกสารนี้ระบุข้อกำหนดฟังก์ชันการทำงานหลัก (Core Functional Requirements) ของ **Hanzero** หลังการปรับทัพ (Realignment) เพื่อให้มุ่งเน้นการเป็นเว็บเรียนภาษาจีนที่สอนเข้าใจง่าย ได้ผลจริง และไม่หลงทางเป็นเกม

---

## 📚 1. คลังคำศัพท์ HSK 3.0 & หมวดหมู่ในชีวิตจริง (Vocab Library / Dictionary)

### 1.1 วัตถุประสงค์
เป็นศูนย์รวมคำศัพท์ทั้งหมดของแพลตฟอร์ม ให้ผู้เรียนสามารถเข้ามาค้นหา, กรองดูตามระดับ HSK, ฟังการออกเสียง และบันทึกคำที่สนใจได้อย่างอิสระตลอดเวลา

### 1.2 ฟังก์ชันการทำงานหลัก
1. **ระบบค้นหา (Universal Search Bar):**
   - ค้นหาได้ทั้ง: คำแปลภาษาไทย, ตัวสะกดพินอิน (มีหรือไม่มีเลขวรรณยุกต์ เช่น `ni` หรือ `ni3`), และตัวอักษรจีน (`你`)
   - แสดงผลลัพธ์แบบ Real-time ขณะพิมพ์
2. **ตัวกรองระดับ & หมวดหมู่ (Filters):**
   - **ตามระดับ HSK:** HSK 1, HSK 2, HSK 3 (ตามมาตรฐาน HSK 3.0)
   - **ตามหมวดหมู่การใช้งาน:** พื้นฐานชีวิตประจำวัน, ร้านอาหาร/เครื่องดื่ม, การเดินทาง/ถามทาง, ตัวเลข/ราคา/เวลา, ครอบครัว/บุคคล
3. **การ์ดคำศัพท์ (Vocab Detail Card):**
   - ตัวอักษรจีนตัวย่อ ขนาดใหญ่ คมชัด
   - พินอิน พร้อมเครื่องหมายวรรณยุกต์มาตรฐาน
   - ปุ่มกดฟังเสียง (Native Web Speech TTS) รองรับโหมดปกติ (1.0x) และโหมดช้า (0.75x)
   - คำแปลภาษาไทยที่เป็นธรรมชาติ
   - คำช่วยจำรากศัพท์ (Mnemonic) และวิธีเขียนลำดับขีด
   - ประโยคตัวอย่างการใช้งานจริง พร้อมคำแปลและเสียงอ่าน
   - **ปุ่ม "บันทึกทบทวน (Add to SRS)":** เพิ่มเข้าคลังทบทวนส่วนตัวในคลิกเดียว

## 📑 2. สารบัญบทเรียนแบบเปิดกว้าง (Open Course Directory)

### 2.1 วัตถุประสงค์
แทนที่ระบบ Quest Map เดิมที่ล็อกด่านและบีบให้ผู้เรียนต้องเล่นตามลำดับ กลายเป็นสารบัญบทเรียนที่ชัดเจน จัดหมวดหมู่สวยงาม และผู้เรียนมีสิทธิเลือกเรียนเรื่องที่ตนเองต้องการได้ทันที

### 2.2 โครงสร้างหลักสูตร (Curriculum Tracks)
1. **🌱 Tier 0: ปูพื้นฐานพินอิน & เสียง (Pinyin Foundation Track):**
   - สำหรับผู้เริ่มต้นจาก 0: พยัญชนะ สระ วรรณยุกต์ กฎการเปลี่ยนเสียง และเส้นขีดพื้นฐาน
2. **🌿 Tier 1: เอาตัวรอดในชีวิตประจำวัน (Survival Chinese Track):**
   - การทักทาย, แนะนำตัว, ซื้อของ/ถามราคา, สั่งอาหาร/ชานม, ถามทาง/ขึ้นรถ, วันที่และเวลา
3. **🎋 Tier 2+: HSK Step-Up:**
   - บทเรียนเข้มข้นไวยากรณ์และคำศัพท์ระดับ HSK 2-3

### 2.3 การแสดงผลการ์ดบทเรียน
- แสดงชื่อบทเรียน 3 ภาษา (จีน - พินอิน - ไทย)
- ระบุเป้าหมายชัดเจน: *"จบบทนี้จะพูดอะไรได้ และได้ศัพท์กี่คำ"*
- แสดงพรีวิวคำศัพท์หลักของบทนั้นๆ
- ปุ่ม **"เริ่มเรียนทันที"** โดยไม่ต้องมีเงื่อนไขการปลดล็อก

## 📖 3. ระบบการสอนแบบเป็นสเต็ป (Step-by-Step Guided Lesson Engine)

### 3.1 ลำดับการเรียนรู้ 4 สเต็ป (4-Step Guided Flow)
เมื่อคลิกเข้าสู่บทเรียน ผู้เรียนจะได้รับการสอนตามลำดับ ไม่เคว้ง ไม่มึน:

```text
[Step 1: แนะนำคำศัพท์] ➔ [Step 2: รูปประโยคและบริบท] ➔ [Step 3: มินิเกมฝึกความจำ] ➔ [Step 4: สรุปความสำเร็จ]
```

1. **Step 1 - Focus Words (เรียนคำศัพท์ทีละคำ):**
   - ครูพาดูทีละคำ: ฟังเสียง Native ➔ ดูรูปปาก/วิธีจำ ➔ ฝึกอ่านตาม ➔ ฝึกคัดลายมือ (HanziWriter)
2. **Step 2 - Context & Dialogue (ดูการใช้ในประโยคจริง):**
   - นำคำที่เพิ่งเรียนมาประกอบเป็นบทสนทนาสั้นๆ 2-4 บรรทัด ฟังเสียงบทสนทนาต่อเนื่อง
3. **Step 3 - Practice Mini-Games (มินิเกมฝึกความจำเสริม):**
   - แบบฝึกหัดสั้นๆ 3-5 ข้อ:
     - ฟังเสียงแล้วเลือกคำศัพท์ที่ถูกต้อง
     - ต่อเลโก้คำศัพท์เป็นประโยค (Sentence Scramble)
     - จับคู่คำศัพท์กับความหมาย
   - **กฎสำคัญ:** ตอบผิดได้ไม่จำกัด ไม่มีการตัดหัวใจ ไม่มี Game Over เพื่อส่งเสริมการกล้าลอง
4. **Step 4 - Lesson Summary (สรุปผลการเรียนรู้):**
   - แสดงการ์ดสรุปคำศัพท์ทั้งหมดที่ผู้เรียนได้เรียนรู้ในวันนี้ พร้อมปุ่มกดฟังเสียงทวน
   - ซิงค์คำศัพท์ทั้งหมดเข้าคลัง SRS อัตโนมัติ

---

## 🎴 4. ระบบทบทวนคำศัพท์อัจฉริยะ (SRS Flashcard Deck)

- ใช้หลักการ Spaced Repetition (SM-2) คำนวณรอบการทบทวนตามความยากง่าย
- ไม่มีการตัดคะแนนหรือหัวใจ เป็นพื้นที่ปลอดภัยสำหรับทบทวนความจำ
- การ์ดทบทวนมีเสียงอ่าน ตัวอย่างประโยค และปุ่มเลือกระดับความจำ (จำได้ง่าย / พอจำได้ / ต้องทบทวนซ้ำ)

---

## 🔊 5. เครื่องยนต์เสียง (Audio Engine Standards)
- Web Speech API Chinese TTS (`zh-CN`) เป็นแกนหลัก
- รองรับปุ่มสลับ Slow Speed (0.75x) / Normal Speed (1.0x)
- มีปุ่มโหมดเงียบ (Silent Mode) สำหรับเรียนในที่สาธารณะ
