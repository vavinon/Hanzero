# 🏮 Hanzero Radical Basics & Stroke Order (รากศัพท์และเส้นขีดอักษรจีน)

เอกสารนี้คือ **พิมพ์เขียวระบบรากศัพท์ (部首 - Bùshǒu) และเส้นขีดอักษรจีน** สำหรับหลักสูตร Hanzero ออกแบบมาเพื่อลบความกลัวตัวอักษรจีนขีดเยอะ เปลี่ยนการท่องจำแบบนกแก้วนกขุนทองให้กลายเป็น **"การต่อเลโก้ภาพแห่งความหมาย" (Visual Lego System)**

---

## 🎨 ปรัชญาการจำตัวอักษรจีนของ Hanzero: "ไม่วาดรูปสุ่ม แต่ต่อบล็อกความหมาย"

1. **อักษรจีนมีชิ้นส่วนจำกัด:** อักษรจีนหลายหมื่นตัว เกิดจากเส้นขีดพื้นฐานเพียง **8 เส้น** และประกอบขึ้นจากหมวดนำหลักประมาณ **200 ตัว (ใช้บ่อยสุดเพียง 40 ตัว)**
2. **หมวดนำบอกความหมาย (Semantics) ส่วนที่เหลือบอกเสียง (Phonetics):** ตัวอักษรจีนกว่า 80% เป็นอักษรภาพผสมเสียง (形声字 - Xíngshēngzì) เช่น:
   * 妈 (mā - แม่): หมวดนำ **女** (ผู้หญิง = ความหมาย) + ตัว **马** (mǎ - ม้า = เสียง)
   * 爸 (bà - พ่อ): หมวดนำ **父** (พ่อ = ความหมาย) + ตัว **巴** (bā = เสียง)
3. **เมื่อรู้หมวดนำ แม้ไม่เคยเห็นคำนั้น ก็เดาหมวดหมู่ความหมายได้ทันที!**

## 1. 🖌️ 8 เส้นขีดพื้นฐานของอักษรจีน (永字八法: The 8 Basic Strokes)

ทุกตัวอักษรจีนเกิดจากการรวมกันของ 8 เส้นขีดหลักนี้:

| ชื่อเส้นขีดจีน | ชื่อภาษาไทย | ทิศทางการลากเส้น | สัญลักษณ์ตัวอย่าง | ในอักษรจีน |
| :---: | :---: | :---: | :---: | :--- |
| **点 (Diǎn)** | จุด | แต้มจากบนซ้ายลงล่างขวา | 丶 | 六 (liù - หก), 门 (mén - ประตู) |
| **横 (Héng)** | เส้นนอน | ลากจากซ้ายไปขวาตรงๆ | 一 | 一 (yī - หนึ่ง), 三 (sān - สาม) |
| **竖 (Shù)** | เส้นตั้ง | ลากจากบนดิ่งลงล่างตรงๆ | 丨 | 十 (shí - สิบ), 中 (zhōng - กลาง) |
| **撇 (Piě)** | เส้นปัดซ้าย | ลากจากขวาบน ปัดโค้งลงซ้ายล่าง | 丿 | 人 (rén - คน), 八 (bā - แปด) |
| **捺 (Nà)** | เส้นตวัดขวา | ลากจากซ้ายบน กดแล้วปล่อยไปขวาล่าง | ㇏ | 大 (dà - ใหญ่), 天 (tiān - ท้องฟ้า) |
| **提 (Tí)** | เส้นตวัดขึ้น | ตวัดจากซ้ายล่าง เฉียงขึ้นขวาบน | ㇀ | 我 (wǒ - ฉัน), 地 (dì - ดิน) |
| **折 (Zhé)** | เส้นหักมุม | ลากเส้นแล้วหักมุม (เช่น แนวนอนแล้วหักลง) | 𠃍 / 𠃋 | 口 (kǒu - ปาก), 日 (rì - พระอาทิตย์) |
| **钩 (Gōu)** | เส้นตะขอ | ลากเส้นแล้วตวัดปลายเหมือนตะขอเบ็ด | 亅 / ㇁ | 小 (xiǎo - เล็ก), 月 (yuè - พระจันทร์) |

## 2. 📐 7 กฎทองลำดับขีด (Stroke Order Rules)

การเขียนตามลำดับขีดที่ถูกต้อง ไม่ใช่แค่เรื่องความสวยงาม แต่ช่วยให้ลายมือสมดุล จดจำคำได้ง่ายขึ้น และเขียนเร็วขึ้น:

```text
1. บนลงล่าง       (Top to Bottom)          ➔ เช่น 三 (sān - สาม), 言 (yán)
2. ซ้ายไปขวา      (Left to Right)          ➔ เช่น 你 (nǐ - เธอ), 仁 (rén)
3. เส้นนอนก่อนเส้นตั้ง (Horizontal before Vertical) ➔ เช่น 十 (shí - สิบ), 丰 (fēng)
4. ปัดซ้ายก่อนตวัดขวา (Left slash before Right)  ➔ เช่น 人 (rén - คน), 文 (wén)
5. นอกเข้าใน       (Outside to Inside)      ➔ เช่น 同 (tóng - เหมือน), 月 (yuè)
6. เข้าไปข้างในก่อน แล้วค่อยปิดประตู (Inside before Closing) ➔ เช่น 回 (huí - กลับ), 国 (guó - ประเทศ)
7. แกนกลางก่อน สองข้างทีหลัง (Center before Sides) ➔ เช่น 小 (xiǎo - เล็ก), 水 (shuǐ - น้ำ)
```
